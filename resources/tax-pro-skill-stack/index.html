02How the stack works

Five skills, five finished files

Each skill is a self-contained instruction set Claude loads on demand. You give it a client's situation, it runs the same structured process every time, and it produces a finished file. No API, no code, no plugins to build.

SkillWhat it doesOutput
tax-savings-reportScreens a client against a fixed strategy library and itemizes every applicable lever with an estimated dollar saving and a total tallyPDF
entity-comparison-modelRuns the same income through sole prop, LLC, S-corp, and C-corp treatment and shows the take-home differenceExcel
roth-conversion-scenarioModels multi-year Roth conversions, finds the bracket room each year, and compares lifetime tax vs doing nothingExcel
cash-balance-plan-projectionSizes the maximum sheltered contribution by owner age and shows the current-year deduction and multi-year savingExcel
financial-plan-overlayOverlays the recovered tax dollars onto the client's existing plan and shows current path vs integrated pathPowerPoint

The point isn't to replace your judgment. It's to take the judgment you already have and turn it into a client-ready document while you're still on the call.

03The prompts

The 5-prompt library

These run in any Claude account. Paste the prompt, then drop in the client data when it asks. Each prompt assumes the matching skill is loaded (see the skill files).

Prompt 1 · Tax savings report
Run the tax-savings-report skill. Here's the client: [client type, income picture, current entity, filing status, state, effective/marginal rate, existing retirement vehicles, real estate and capital gains events, what their current CPA has already implemented]. Screen against the full strategy library, itemize what applies with an estimated dollar saving and a confidence note, and give me the total tally split into firm estimate vs needs-validation. Output the PDF.
Prompt 2 · Entity comparison model
Run the entity-comparison-model skill. Business net profit is [X], reasonable comp estimate is [Y] (or model low/mid/high), filing status [Z], state [state], other household income [amount], benefits run through the business [list]. Build the Excel with sole prop, S-corp, and C-corp tabs, a comparison table, and a breakeven tab. Pull every scenario from the Inputs tab.
Prompt 3 · Roth conversion scenario
Run the roth-conversion-scenario skill. Account holder age [X], target retirement age [Y], pre-tax balances [amount], expected ordinary income by year [list], filing status [Z], state [state], planning window [years], assumed growth [%], assumed future tax rate [%], outside cash to pay conversion tax [yes/no]. Build the bracket-filling schedule and compare lifetime tax against the do-nothing path.
Prompt 4 · Cash balance plan projection
Run the cash-balance-plan-projection skill. Owner age [X], net business profit [amount] and how stable it is, owner W-2 comp [amount], employee census [ages and comp], existing 401k/profit-sharing [amounts], marginal rate [%], state [state], planning window [years]. Size the contribution capacity by age, show the current-year deduction, the employee funding cost, and the multi-year saving vs 401k-only.
Prompt 5 · Financial plan overlay
Run the financial-plan-overlay skill. Current plan: [allocation, balances, contribution rates, risk profile, goals]. Identified annual tax saving: [amount from the report]. Redeploy the savings into [retirement / taxable / debt paydown]. Assumed growth [%], horizon [years]. Build the deck with current path vs integrated path and call out the ending figure as one number.

04The skill files

The five .skill files

How to load them. Drop the .skill into your Claude skills directory (or your Cowork plugin's skills folder). Claude reads the description line in each file's front matter and fires the right skill when your prompt matches. You don't have to name the skill by hand most of the time. The prompts above name it explicitly so there's no ambiguity.

What's inside each file. Every skill follows the same shape: the inputs to collect first, the fixed process it runs, the output structure, and a set of hard rules that keep the numbers honest (no invented figures, every soft number flagged for validation, all rate years labeled). That last part matters. A deliverable that overstates savings is worse than no deliverable.

05Before you run them

The exact data inputs each skill needs

Gather these before you run the prompt. Walking in with the inputs ready is the difference between a three-minute output and a twenty-minute back-and-forth.

SkillMust-have inputs
tax-savings-reportClient type, income picture (W-2 / K-1 / distributions), current entity, filing status and state, effective/marginal rate, existing retirement vehicles, real estate and capital gains events, what the current CPA already implemented
entity-comparison-modelBusiness net profit, reasonable comp estimate, filing status, state, other household income, benefits run through the business, number of owners
roth-conversion-scenarioAges, pre-tax balances, expected income by year, filing status, state, planning window, growth rate, assumed future tax rate, outside cash to pay the tax
cash-balance-plan-projectionOwner age(s), net profit and stability, owner W-2 comp, employee census (ages and comp), existing plan contributions, marginal rate, state, planning window
financial-plan-overlayCurrent allocation and balances, contribution rates, risk profile, goals, the identified annual saving, how it's redeployed, growth rate, horizon

When a number isn't available, the skills are built to mark it "needs data" rather than inventing it. Use that. A report that's honest about its soft spots earns more trust than one that pretends to be precise.

07Which one when

The decision tree

Which skill to run when. Read top to bottom for a given client.

If the client is...And the situation is...Run this first
Any high earner, new to youYou don't yet know where the leaks aretax-savings-report (it screens everything and tells you what to model next)
A business ownerStill a sole prop or unsure their structure fitsentity-comparison-model
Anyone with large pre-tax balancesHas a low-income year coming, or fears higher future ratesroth-conversion-scenario
An owner or practice professionalStrong stable profit, already maxing the 401kcash-balance-plan-projection
Any client after savings are foundWants to see what the recovered dollars become long-termfinancial-plan-overlay

The usual sequence: run the savings report first to find the levers, model the two or three biggest with the matching skills, then close with the overlay so the client sees the compounding effect. The report tells you what to model. The models prove the numbers. The overlay makes it land.
